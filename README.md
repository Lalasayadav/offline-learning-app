# 📚 Offline-First AI Micro-Learning & Spaced Repetition Platform

An enterprise-ready, cross-platform mobile application built with **Flutter** and **SQLite** designed to make learning accessible, intelligent, and completely resilient to spotty network connectivity.

---

## 📌 Problem Statement
Students and professionals living in areas with poor or intermittent internet access often struggle to access modern AI-driven educational tools. Traditional EdTech apps fail to function offline, interrupting daily study schedules and causing friction in learning habits.

## 💡 Solution
This app provides an **offline-first micro-learning experience** powered by spaced-repetition algorithms and local caching. Lessons and flashcards generated by AI are synced locally to an on-device SQLite database, allowing users to review, practice, and track their retention completely offline without any network latency.

---

## ✨ Key Features
- **Offline-First Storage:** Full local persistence using `sqflite` to read and write review data without an active network connection.
- **Spaced Repetition Engine:** Intelligently calculates optimal flashcard review dates based on user performance to improve memory retention.
- **AI-Powered Lesson Fetching:** Syncs structured micro-lessons and flashcards when an internet connection is available.
- **Clean Architecture:** Built with a modular folder structure (Services, Models, Views) for scalability and ease of testing.

---

## 🛠️ Tech Stack & Architecture
- **Framework:** Flutter (Dart)
- **Local Database:** SQLite (`sqflite`)
- **State Management:** Provider / Riverpod
- **Architecture:** Repository Pattern (Model-View-ViewModel / Clean Architecture)
